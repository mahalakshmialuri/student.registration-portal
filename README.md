# Student Registration Portal

A simple student registration form created using HTML5.

## About the Project
This project provides a student registration form to collect personal, academic, skills, address, and additional details.

## Features
- Personal details
- Academic details
- Programming languages and technical skills
- Preferred job role and hobbies
- Address details
- Resume upload field
- Form validation using HTML attributes
- Submit and reset buttons

## Technologies Used
- HTML5
